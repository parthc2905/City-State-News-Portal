Test Cases for Report Models

Test Case 1: Verify CitizenReport default status
Description: Ensure that when a new CitizenReport instance is instantiated without specifying a status, its default status is 'pending'.

Description: Verify that the max_length attribute of the title field in CitizenReport is exactly 255.
